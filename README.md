# HydroMetView

Веб-приложение для мониторинга погоды и гидрологической обстановки в России.
Адресовано дачникам, рыбакам, туристам и жителям паводкоопасных районов.

## Стек

- **React 18** + **Vite 5** (фронтенд-only, без бэкенда)
- **Tailwind CSS** для стилей
- **Leaflet** + react-leaflet для интерактивной карты
- **Recharts** для графиков
- **WeatherAPI.com** — данные о погоде и качестве воздуха
- **PWA** с Service Worker'ом для оффлайн-режима

## Возможности

- Текущая погода и прогноз на 7 дней для городов России
- Качество воздуха (EPA AQI 1-6)
- Официальные штормовые/паводковые предупреждения
- Карта гидропостов с моделью уровня воды
- Прогноз подтопления на 48 часов
- Сравнение городов
- Персональные режимы (рыбак / дачник / турист / житель паводка)
- Тёмная/светлая темы, поддержка `prefers-color-scheme`
- Push-уведомления (с уважением к настройкам пользователя)
- Шеринг карточки дня как PNG-изображения

## Локальная разработка

```bash
npm install
cp .env.example .env       # затем впишите свой VITE_WEATHER_API_KEY
npm run dev                # http://localhost:5173
```

### Тесты

```bash
npm run test               # watch mode
npm run test:run           # одноразовый прогон
```

### Production-сборка

```bash
npm run build              # → dist/
npm run preview            # локальный просмотр сборки
```

## Деплой на Vercel

1. Запушьте репозиторий в GitHub
2. Импортируйте проект на [vercel.com](https://vercel.com)
3. В настройках добавьте environment variable: `VITE_WEATHER_API_KEY` со значением из [weatherapi.com](https://weatherapi.com)
4. Нажмите Deploy

`vercel.json` уже настроен — SPA-роутинг, заголовки безопасности и кеширование работают из коробки.

## Лимитации

- **Аутентификация** хранится в LocalStorage браузера — аккаунты не синхронизируются между устройствами. Подходит для демо/MVP; для production-сценариев нужен реальный бэкенд (Supabase / Firebase).
- **API-ключ WeatherAPI** виден в бандле (особенность frontend-only архитектуры). На бесплатном тарифе WeatherAPI это приемлемо; для high-traffic нужен серверный прокси.
- **Данные гидропостов** моделируются на основе реальной погоды в координатах поста, т.к. публичного API Roshydromet нет.
